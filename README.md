# Diplom_2
# Автотесты API для сервиса Stellar Burgers 🍔

Проект содержит автоматизированные тесты для проверки API сервиса Stellar Burgers. Тесты покрывают функциональность регистрации, логина пользователей и создания заказов.

## Технологический стек
* **Python 3**
* **Pytest** (тестовый фреймворк)
* **Requests** (библиотека для HTTP-запросов)

## Структура проекта
* `tests/` — папка с тестами (User и Order).
* `conftest.py` — общие фикстуры (автоматическое создание и удаление пользователей).
* `urls.py` — централизованное хранение эндпоинтов API.

##  Как запустить

### 1. Подготовка
Убедитесь, что у вас установлен Python. Склонируйте проект и перейдите в папку с ним.
