# Дипломный проект: UI-автоматизация Stellar Burgers (Часть 2)

Второй этап дипломной работы, посвященный автоматизации ключевых пользовательских сценариев в браузере с использованием Selenium WebDriver.

## 🛠 Технологии и инструменты
* **Язык:** Python 3.x
* **Тест-фреймворк:** Pytest
* **Инструмент автоматизации:** Selenium WebDriver
* **Архитектура:** Page Object Model (POM)

## 🧪 Что протестировано в проекте:

### 1. Регистрация пользователя (`test_registration.py`):
* Успешная регистрация с валидными данными.
* Валидация ошибки при вводе некорректного пароля (менее 6 символов).

### 2. Вход в систему (`test_login.py`):
* Вход через кнопку «Войти в аккаунт» на главной странице.
* Вход через кнопку «Личный кабинет».
* Вход через форму регистрации и форму восстановления пароля.

### 3. Личный кабинет и навигация (`test_personal_account.py`):
* Переход в раздел «Личный кабинет».
* Переход из личного кабинета в «Конструктор» по клику на логотип и кнопку.
* Выход из аккаунта (Logout).

### 4. Раздел «Конструктор» (`test_constructor.py`):
* Работа переключателей разделов («Булки», «Соусы», «Начинки»).

## 📂 Структура проекта
* `locators/` — централизованное хранение локаторов элементов (ID, XPATH, CSS).
* `pages/` — методы взаимодействия со страницами сайта.
* `tests/` — тестовые сценарии на Pytest.
* `conftest.py` — фикстуры для инициализации и закрытия драйвера браузера.
