# Автоматизация UI-тестирования Stellar Burgers (Diplom 2)

Вторая часть дипломного проекта, посвященная автоматизации пользовательского интерфейса (UI) с использованием Selenium WebDriver.

## 🛠 Технологии и инструменты
* **Язык:** Python 3.x
* **Тест-фреймворк:** Pytest
* **Инструмент автоматизации:** Selenium WebDriver
* **Архитектура:** Page Object Model (POM)

## 🧪 Что протестировано в проекте:

### 1. Личный кабинет (`test_personal_account.py`):
* Переход по клику на кнопку «Личный кабинет».
* Переход из личного кабинета в «Конструктор» и по клику на логотип Stellar Burgers.
* Выход из аккаунта (кнопка «Выйти»).

### 2. Регистрация и вход (`test_login.py` и `test_registration.py`):
* Успешная регистрация пользователя.
* Ошибка при вводе некорректного пароля (менее 6 символов).
* Вход через кнопку «Войти в аккаунт» на главной.
* Вход через кнопку «Личный кабинет».
* Вход через форму регистрации и форму восстановления пароля.

### 3. Конструктор (`test_constructor.py`):
* Работа переключателей разделов: «Булки», «Соусы», «Начинки» (проверка активации нужной вкладки при клике).

## 📂 Структура проекта
* `pages/` — содержит описание страниц (локаторы и методы) согласно паттерну Page Object.
* `tests/` — наборы автотестов, разделенные по функциональным модулям.
* `conftest.py` — конфигурация тестов и описание фикстур (например, запуск и закрытие браузера).
